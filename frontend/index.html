Next-Gen Biometric Intelligence

Engineered for instantaneous, tamper-proof attendance verification across high-density campus lecture halls and enterprise venues.

01 / DETECTION ENGINE
OpenCV YuNet Neural Localization
High-speed single-stage anchor-free convolutional detector. Accurately localizes multi-subject facial bounding boxes and regresses 5 canonical facial landmarks (pupils, nose tip, mouth corners) in sub-5ms under extreme lighting and yaw angles.
640×480 Resolution ~4.2ms Latency 5-Point Regression Anchor-Free FPN
02 / DEEP EMBEDDING
ArcFace (IResNet-100) Hypersphere
Extracts 512-dimensional normalized biometric feature vectors using Additive Angular Margin loss (s=64, m=0.5). Maximizes geodesic separation between different identities while enforcing tight intra-class clustering for discriminating lookalikes.
512-D Latent Tensor L2 Norm: ||x|| = 1.0 Angular Margin: m=0.5 Cosine Metric
03 / VERIFICATION
Vectorized Cosine Roster Search
Computes pairwise matrix dot products between captured face vectors and pre-enrolled student templates. The batched cosine distance search identifies all present students concurrently in a single mathematical pass with zero queue delay.
Cosine Threshold ≥ 0.50 < 2ms Batch Search 99.83% Accuracy Zero Duplicate Proxy
04 / DATA & AUDIT
Supabase PostgreSQL Synchronization
End-to-end cryptographic synchronization with Supabase PostgreSQL over SSL. Verification logs, student confidence scores, high-resolution audit timestamps, and automated attendance reports are immediately aggregated and accessible.
